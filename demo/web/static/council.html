The council

Each tab on the left is a context: a pinned, held context on the daemon (the repo's memory, Amy's standing guidance, the live session). An action typed on the right is one opinion read across every included context, in tab order: each context answers the spec's question on its own, after its own head.

The pooled verdict combines them: linear averages the probabilities (some context supports it), loglinear multiplies them (the contexts agree on it). Mass weights trust a context by how much of its probability landed on the options at all. The daemon never picks: the verdict here is the pool's top option, ties to the earlier one. The page recomputes the daemon's pool from the reads and stops loudly if the two differ.

Two specs: one reads the verdict cold, at the first slot; the other has each context describe the action first, so every description comes from inside its own context. Switching re-reads the recent decisions.

Change a context (edit, ask, include or exclude) and the last decisions are re-read under the new set: the cards whose verdict flipped light up in the color of the context that changed. Replay re-reads one: a repeated read is identical, so the bits match.

Ask runs a chat in that tab and the reply joins it. A chat never takes a reply back as text, so a tab's later asks continue the chat that wrote its replies, and a tab whose replies no chat holds any more (edited, restarted) can't be asked until the reply is deleted.
